ICT Glossary

HTML
HyperText Markup Language - the standard language used to create and structure web pages.
URL
Uniform Resource Locator - the address of a resource on the internet, e.g https:// www.isbat.ac.ug
Browser
Software that retrieves and displays web pages, e.g. Google Chrome, Firefox,Microsoft Edge.
